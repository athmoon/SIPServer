# SIP服务端配置说明文档

## 系统要求

- Android 8.0 (API 26) 或更高版本
- 建议设备具备root权限（用于高级功能）
- 至少1GB RAM
- 稳定的WiFi网络连接

## 功能概述

本应用是一个运行在Android设备上的完整SIP服务端，支持：

1. **SIP客户端注册** - 支持4位数字分机号注册
2. **内部通话** - 已注册客户端之间互相拨打
3. **外呼功能** - 通过SIM卡拨打外部电话
4. **来电转发** - SIM卡来电自动转发到SIP客户端
5. **短信功能** - SIP MESSAGE与SIM卡短信互通

## 安装步骤

### 1. 安装APK

```bash
adb install SIPServer.apk
```

### 2. 授予权限

首次启动时，应用会请求以下权限：
- 电话权限（CALL_PHONE, READ_PHONE_STATE）
- 短信权限（SEND_SMS, RECEIVE_SMS, READ_SMS）
- 网络权限（INTERNET, ACCESS_NETWORK_STATE）
- 开机启动权限（RECEIVE_BOOT_COMPLETED）

**必须授予所有权限才能正常使用**

### 3. 电池优化设置

为确保服务稳定运行，需要将应用加入电池优化白名单：

1. 打开系统设置
2. 进入"电池"或"省电模式"
3. 找到"SIP服务端"
4. 选择"不限制"或"允许后台活动"

## SIP服务配置

### 基本参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| SIP端口 | 5060 | SIP信令监听端口 |
| SIP域 | sip.local | SIP域名，客户端注册时使用 |

### 配置步骤

1. 打开应用，点击"设置"按钮
2. 输入SIP端口号（建议使用默认5060）
3. 输入SIP域名（可使用默认值或自定义）
4. 点击"保存设置"
5. 重启服务使配置生效

## SIP客户端配置

### 软电话配置示例（以Zoiper为例）

```
账号类型: SIP
用户名/分机号: 1001
密码: （留空或任意，当前版本无密码验证）
域名/服务器: <安卓板IP地址>
端口: 5060
传输协议: UDP
```

### 分机号规则

- 必须为4位数字（如：1001, 2002, 9999）
- 5位及以上号码视为外部号码，会通过SIM卡外呼

## SIM卡配置

### 双卡设置

1. 打开应用，点击"SIM卡配置"按钮
2. 选择默认外呼SIM卡（SIM1或SIM2）
3. 配置来电转发：
   - 勾选"来电转发到分机"
   - 输入目标分机号（如：1001）
4. 配置短信转发：
   - 勾选"短信转发到分机"
   - 输入目标分机号

### 外呼规则

当SIP客户端拨打：
- **4位号码**（如1001）→ 内部呼叫，路由到已注册客户端
- **5位及以上号码**（如13800138000）→ 外部呼叫，通过SIM卡拨打

## 网络配置

### 局域网部署

1. 确保安卓板和SIP客户端在同一局域网
2. 安卓板建议使用固定IP地址
3. 在路由器上为安卓板设置DHCP静态绑定

### 端口开放

如需从外网访问，需要在路由器上开放：
- UDP 5060（SIP信令）
- UDP 10000-20000（RTP媒体，如需语音通话）

## 服务管理

### 启动服务

点击"启动服务"按钮，服务将在前台运行并显示通知。

### 停止服务

点击"停止服务"按钮，服务将完全停止。

### 开机自启动

授予开机启动权限后，服务会在设备启动时自动运行。

## 高级配置

### 日志查看

日志文件存储位置：
```
/storage/emulated/0/Android/data/com.sipserver/files/logs/
```

### 配置文件

配置存储在SharedPreferences中，路径：
```
/data/data/com.sipserver/shared_prefs/sip_server_config.xml
```

## 注意事项

1. **WiFi休眠**：在WiFi设置中关闭"休眠时保持WiFi连接"
2. **后台限制**：部分厂商ROM会限制后台服务，需在系统设置中允许
3. **SIM卡状态**：确保SIM卡已插入且状态正常
4. **网络稳定性**：建议使用有线网络（如USB网卡）以提高稳定性
