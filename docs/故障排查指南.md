# SIP服务端故障排查指南

## 常见问题及解决方案

### 1. 服务无法启动

**症状**：点击"启动服务"后服务立即停止或显示错误

**排查步骤**：

1. 检查权限是否全部授予
   ```
   设置 → 应用 → SIP服务端 → 权限 → 确保所有权限已开启
   ```

2. 检查端口是否被占用
   ```
   adb shell netstat -an | grep 5060
   ```
   如果端口被占用，修改SIP端口后重试

3. 查看日志
   ```
   adb logcat -s SIPStack:* SIPService:* LogUtil:*
   ```

**常见错误码**：

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| Permission denied | 权限未授予 | 到设置中授予权限 |
| Address already in use | 端口被占用 | 更换SIP端口 |
| Network unreachable | 无网络连接 | 检查WiFi连接 |

### 2. 客户端无法注册

**症状**：SIP软电话显示注册失败或超时

**排查步骤**：

1. 确认服务已启动
   - 主界面状态应显示"运行中"

2. 检查网络连通性
   ```bash
   # 从客户端设备ping安卓板
   ping <安卓板IP地址>
   ```

3. 检查防火墙设置
   - 安卓板可能安装了防火墙应用，需放行UDP 5060

4. 检查客户端配置
   - 服务器地址是否正确
   - 端口是否正确（默认5060）
   - 传输协议是否为UDP

5. 查看服务端日志
   ```
   adb logcat | grep "REGISTER"
   ```

**常见错误**：

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 注册超时 | 网络不通 | 检查网络连接 |
| 403 Forbidden | 分机号格式错误 | 使用4位数字分机号 |
| 404 Not Found | 服务器地址错误 | 检查服务器IP和端口 |

### 3. 内部通话失败

**症状**：拨打内部号码时提示失败或无响应

**排查步骤**：

1. 确认双方都已注册
   - 主界面客户端列表应显示两个客户端

2. 检查被叫客户端状态
   - 客户端状态应为"在线"，而非"忙线"

3. 查看呼叫日志
   ```
   adb logcat | grep "INVITE"
   ```

**可能原因**：
- 被叫未注册或已过期
- 被叫忙线中
- NAT穿透问题（不同网段）

### 4. 外呼失败

**症状**：拨打外部号码时提示失败

**排查步骤**：

1. 检查SIM卡状态
   - SIM卡配置界面应显示SIM卡信息
   - SIM卡状态应为"就绪"

2. 检查权限
   ```
   adb shell pm list permissions -g com.sipserver
   ```
   确认有CALL_PHONE权限

3. 手动拨打电话测试
   - 使用系统拨号器拨打相同号码
   - 如果系统拨号器也失败，说明是SIM卡问题

4. 查看日志
   ```
   adb logcat | grep "外呼"
   ```

**可能原因**：
- SIM卡未插入或损坏
- SIM卡余额不足
- 呼叫权限未授予
- 号码格式不正确

### 5. 来电转发不工作

**症状**：SIM卡来电时SIP客户端未收到呼叫

**排查步骤**：

1. 确认来电转发已配置
   - SIM卡配置中"来电转发到分机"已勾选
   - 目标分机号已填写

2. 确认目标客户端已注册
   - 客户端列表中应显示目标分机

3. 检查电话状态权限
   ```
   adb logcat | grep "PhoneStateReceiver"
   ```

4. 测试来电接收
   - 拨打SIM卡号码，观察是否触发转发

**可能原因**：
- READ_PHONE_STATE权限未授予
- 目标客户端未注册
- 转发功能未启用

### 6. 短信发送失败

**症状**：通过SIP MESSAGE发送短信失败

**排查步骤**：

1. 检查短信权限
   ```
   adb shell pm list permissions -g com.sipserver | grep SMS
   ```

2. 检查SIM卡状态

3. 查看短信发送日志
   ```
   adb logcat | grep "SMS"
   ```

4. 手动发送短信测试
   - 使用系统短信应用发送测试

### 7. 服务自动停止

**症状**：服务运行一段时间后自动停止

**排查步骤**：

1. 检查电池优化设置
   ```
   设置 → 电池 → 电池优化 → SIP服务端 → 不优化
   ```

2. 检查后台限制
   - MIUI: 设置 → 应用设置 → 应用管理 → SIP服务端 → 省电策略 → 无限制
   - EMUI: 设置 → 应用 → 应用启动管理 → SIP服务端 → 手动管理，全部开启
   - ColorOS: 设置 → 电池 → 应用快速冻结 → SIP服务端 → 关闭

3. 关闭WiFi休眠
   ```
   设置 → WLAN → 高级设置 → 在休眠状态下保持WLAN连接 → 始终
   ```

4. 检查系统日志
   ```
   adb logcat | grep -E "SIPService|kill"
   ```

### 8. 服务耗电严重

**症状**：服务运行时电量消耗过快

**优化建议**：

1. 减少日志级别
   - 在配置中禁用调试日志

2. 延长客户端过期检查间隔

3. 使用有线网络替代WiFi

### 9. 语音质量问题

**症状**：通话声音断续或延迟

**排查步骤**：

1. 检查网络质量
   ```bash
   ping -c 100 <对端IP地址>
   ```
   查看丢包率和延迟

2. 检查WiFi信号强度
   - 确保安卓板WiFi信号良好

3. 检查CPU占用
   ```
   adb shell top | grep sipserver
   ```

**优化建议**：
- 使用5GHz WiFi频段
- 减少同时通话数量
- 关闭不必要的后台应用

### 10. 开机不自启动

**症状**：设备重启后服务未自动运行

**排查步骤**：

1. 检查开机启动权限
   ```
   adb shell pm list permissions -g com.sipserver | grep BOOT
   ```

2. 检查自启动设置
   - MIUI: 设置 → 应用设置 → 自启动管理 → SIP服务端 → 开启
   - EMUI: 设置 → 应用 → 应用启动管理 → SIP服务端 → 自动启动

3. 查看启动日志
   ```
   adb logcat | grep "BootReceiver"
   ```

## 日志收集方法

### 方法1：adb logcat

```bash
# 收集所有日志
adb logcat > sipserver_log.txt

# 只收集SIP相关日志
adb logcat -s SIPStack:* SIPService:* ClientManager:* CallManager:* > sipserver_sip_log.txt
```

### 方法2：应用内日志

日志文件位置：
```
/storage/emulated/0/Android/data/com.sipserver/files/logs/
```

## 重置应用

如果以上方法都无法解决问题，可以尝试重置应用：

```bash
# 清除应用数据
adb shell pm clear com.sipserver

# 卸载重装
adb uninstall com.sipserver
adb install SIPServer.apk
```

## 技术支持

如问题仍未解决，请提供以下信息：

1. 设备型号和Android版本
2. 详细的问题描述和复现步骤
3. logcat日志文件
4. 服务状态截图

## 已知限制

1. **NAT穿透**：当前版本不支持STUN/TURN，仅支持局域网部署
2. **加密**：当前版本未实现TLS加密
3. **认证**：当前版本未实现摘要认证，任何分机号都可注册
4. **并发限制**：建议同时注册客户端不超过10个
